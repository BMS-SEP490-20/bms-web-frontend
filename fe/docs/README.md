# Documentation Directory

Thư mục này chứa tài liệu tổng hợp về dự án.

## 📁 Cấu Trúc

- **PROJECT_DOCUMENTATION.md** - Tài liệu tổng hợp về dự án (workflow, routes, API, roles)
- **archive/** - Các file documentation cũ đã được archive

## 📚 Tài Liệu Chính

### Root Directory:
- **README.md** - Tổng quan dự án, tính năng, cài đặt
- **SETUP.md** - Hướng dẫn setup và cấu hình
- **ROLE_BASED_AUTHORIZATION_SYSTEM.md** - Hệ thống phân quyền
- **REFACTORING_PLAN.md** - Kế hoạch refactoring (tham khảo)

### src/ Directory:
- **LAB_USER_WORKFLOW_FINAL.md** - Workflow cuối cùng của Lab User
- **WORKFLOW_STATUS_EXPLAINED.md** - Giải thích status và workflow
- **docs/API_LIST.md** - Danh sách API endpoints

## 🎯 Mục Đích

Các file documentation này giúp:
- AI chat hiểu được cấu trúc và workflow của dự án
- Developers mới nhanh chóng nắm bắt dự án
- Maintain và phát triển dự án hiệu quả hơn

## 📝 Lưu Ý

- Các file trong `archive/` là các file cũ đã được cleanup
- Chỉ giữ lại các file quan trọng nhất
- Cập nhật documentation khi có thay đổi lớn
